# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting form:

https://github.com/ribbons-digital/pi-warm-cache/security/advisories/new

Include the affected version, a short impact description, and safe reproduction steps.
Do not include provider credentials, access tokens, prompt contents, or other private data.

## Supported versions

Only the latest published version receives security fixes.
